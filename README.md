# HA-Voice-Preview-RU

Русскоязычный набор материалов для настройки Home Assistant Voice Preview Edition (ESP32-S3) с собственной wake word.

## Что это

Репозиторий собран как практический набор для повторения моего сценария:

- конфиги ESPHome;
- wake word «ЭЙ ОЛЕНЬ»;
- примеры Home Assistant;
- заметки по локальному голосовому управлению;
- документация по установке и отладке.

## Что проверено

- ESPHome 2026.8.1 — успешная сборка.
- ESPHome 2026.9.1 — успешная проверка конфигурации в Home Assistant.
- Wake word «ЭЙ ОЛЕНЬ» найдена и восстановлена.
- Рабочая колонка и исходная прошивка не затронуты.

## Структура репозитория

### `esphome/`
Конфиги прошивки и вспомогательные файлы для Home Assistant Voice Preview Edition.

### `wake-word/`
Файлы модели wake word и связанные материалы.

### `home-assistant/`
Примеры автоматизаций, скриптов и voice pipeline.

### `local-ai/`
Заметки и примеры по локальному AI/LLM.

### `docs/`
Подробные инструкции:
- `installation.md`
- `configuration.md`
- `troubleshooting.md`

### `examples/`
Готовые примеры и шаблоны конфигураций.

## Быстрый старт

1. Откройте `docs/installation.md`.
2. Скопируйте пример конфигурации из `esphome/`.
3. Подготовьте свои значения в шаблоне настроек.
4. Соберите прошивку через ESPHome Device Builder.
5. Проверьте работу wake word и интеграцию с Home Assistant.
