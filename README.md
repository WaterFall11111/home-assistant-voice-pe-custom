# Home Assistant Voice PE — Custom Wake Word

Русскоязычное руководство по настройке и доработке
Home Assistant Voice Preview Edition (ESP32-S3).

## Возможности

- Русская фраза активации «ЭЙ ОЛЕНЬ».
- Поддержка собственной обученной Wake Word.
- Настройка чувствительности распознавания.
- Локальное голосовое управление Home Assistant.
- Работа с Speech-to-Phrase, Whisper и Piper.
- Возможность подключения локального LLM.
- Обновление прошивки через ESPHome Device Builder.

## Совместимость

Устройство: Home Assistant Voice Preview Edition.

Проверено:
- ESPHome 2026.8.1 — успешная компиляция.
- ESPHome 2026.9.1 — успешная компиляция.

Важно: новая конфигурация ещё не проверена
путём установки на физическое устройство.

## Документация

Подробные инструкции будут добавлены в docs/.

## Безопасность

Проект не должен содержать:
- Пароли Wi-Fi.
- API-ключи.
- Личные IP-адреса.
- Приватные конфигурации Home Assistant.
