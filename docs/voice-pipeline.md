# Настройка голосовых ассистентов в Home Assistant

Для работы колонки в Home Assistant настраиваются два или три ассистента под разные задачи.

## 1. Быстрый ассистент (ha-fast)
Служит для мгновенного управления устройствами (свет, выключатели, таймеры).

- **Язык:** Русский
- **Распознавание речи (STT):** Speech-to-Phrase
- **Диалоговая система:** Home Assistant
- **Синтез речи (TTS):** Piper (голос `ruslan (medium)`)

## 2. Ассистент с локальным ИИ (ha-voice)
Служит для сложных вопросов и общения с нейросетью.

- **Язык:** Русский
- **Распознавание речи (STT):** faster-whisper
- **Диалоговая система:** Local LLM Server (home-agent AI Agent)
- **Синтез речи (TTS):** Piper (голос `ruslan (medium)`)
- **Предпочитать локальную обработку:** Включено

## Настройка переключения на колонке
В настройках устройства в Home Assistant выберите:
- **Основной ассистент:** `ha-fast`
- **Второй ассистент:** `ha-voice`
